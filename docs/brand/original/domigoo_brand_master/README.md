# DOMIGOO — Paquete maestro de identidad (concepto v1.0)

## Contenido
- `svg/domigoo-horizontal-dark.svg`: logotipo horizontal sobre índigo.
- `svg/domigoo-horizontal-light.svg`: logotipo horizontal sobre fondo claro.
- `svg/domigoo-vertical.svg`: composición vertical.
- `svg/domigoo-app-icon.svg`: icono cuadrado para app.
- `svg/domigoo-monochrome-dark.svg`: versión monocromática oscura.
- `svg/domigoo-monochrome-light.svg`: versión monocromática clara.
- `png/`: exportaciones PNG de alta resolución.
- `docs/design-tokens.css`: variables CSS de marca.

## Paleta
- Índigo profundo: #29243E
- Turquesa mineral: #79D5D0
- Plata: #C0C6D4
- Blanco neutro: #F5F7FA

## Tipografía
- Marca/titulares: Montserrat (Bold/SemiBold).
- Interfaz y textos: Inter (Regular/Medium).

## Nota importante
Este es un primer paquete vectorial conceptual construido a partir de la dirección visual seleccionada.
El símbolo está redibujado como geometría SVG editable y simplificada; no es un calco exacto de la lámina de referencia.
Antes de producción comercial:
1. Revisión profesional de proporciones y legibilidad a 24–32 px.
2. Prueba de impresión y bordado.
3. Confirmación de licencias tipográficas y disponibilidad marcaria.
4. Sustituir fuentes de sistema si el entorno no tiene Montserrat/Inter instaladas.
